# climate-learning-framework
A comprehensive learning framework for climate finance, climate resilience, and sustainability &amp; climate change topics

## 📚 Chapters (Bab)

1. **[Just Transition](bab/01_Just_Transition.json)** — justice principles, policy timeline, corporate application
2. **[Climate Investment](bab/02_Climate_Investment.json)** — financing gap, instruments, market trends
3. **[Food & Nature](bab/03_Food_and_Nature.json)** — nature-based solutions, regenerative agriculture, case studies
4. **[Material & Circular Economy](bab/04_Material_and_Circular_Economy.json)** — the 9R framework, circularity metrics, business models

Each chapter includes core definitions, key facts, real-world case studies, a "Top 20 Exam Facts" recap, and an "Interview Prep" section with sample Q&A.
